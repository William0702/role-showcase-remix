# 路径准备与首次使用引导

自动模式优先按[自动入口](automatic-workflow.md)：用户可只提供视频，Agent在可写工作区自主建批次并回报位置。以下用户逐项指定目录的流程仅在用户要求指定路径时使用，不强制每批询问已可合理确定的目录。

## 自动输出时机

使用随包 `install.cmd` 或 `install.ps1` 安装时，安装脚本验证文件并完成复制后，自动输出 `startup-guide.md`。执行 agent 通过其他方式安装本包时，安装完成后在聊天中输出同一引导，不只说“安装成功”。普通技能文件没有产品级安装完成事件；首次调用本技能且尚未有本批路径记录时，也须主动显示该引导并收集缺失信息。已明确路径或继续已有批次时，回报现有路径，补充缺失项，不重问整个流程。

## 确定两个路径

区分母片路径和本批制作目录，技能安装目录不作制作目录。用户提供一个项目目录且母片位于其中时，推荐该项目的独立批次目录；用户指定母片目录但未指定输出位置时，推荐母片目录的同级制作批次目录，等用户选择后初始化。不要把例子、历史测试路径或历史命名当成本批决定。用户只要求准备目录时，创建明确指定的目录并输出母片投放位置，等素材就位后再入库，不自动剪辑。

用户确认制作目录后运行 `init --project <制作目录>`；新建 `母片` 与 `.remix/batch.json`，并建立 `拉片审阅`、`切分`、`混剪/成品`、`混剪/组合方案`、`成品核对`。已有项目只检查复用，不覆盖配置或文件。实际路径必须回报给用户。

本工具只读取项目内源目录：母片在制作目录内时，inventory 使用其项目相对路径；外部母片目录先复制到本批 `母片` 再读取。说明原始目录和入库目录各是什么，只复制本批素材，不移动原件；目标同名文件先核对哈希，相同可复用，不同内容保留独立名字，不覆盖。母片位于外部时记录原始完整路径及入库映射，以便后续新增素材核对，不能声称CLI可直接读取任意外部路径。

在 `.remix/workspace.json` 记录实际决定：

```json
{
  "original_source_dir": "用户提供的母片目录完整路径",
  "working_dir": "实际制作目录完整路径",
  "ingest_dir": "项目内入库目录完整路径",
  "output_dir": "制作目录/混剪/成品",
  "mode": "showcase、story或尚待素材审阅",
  "path_decision": "用户的实际路径选择或授权原文"
}
```

以上是结构示例，必须填实际路径。共用入口只确认路径和必要模式；展示或剧情的参数仍在相应模块确定，不把展示配额传给剧情。初始化配置中的默认值只是工具默认值，不算用户确认。

开始制作前用简短文字回报：母片来源、入库位置、本批工作目录、成品位置、发现视频数量及还缺哪些决定。随后进入共用入库与逐帧审阅。新批次和增量批次遵守原有配额及审批规则。

## 随包安装

完整解压后双击 `install.cmd`，默认安装到当前用户的Codex技能目录；存在CODEX_HOME时使用该目录的skills子目录。已有同名技能时停止并告知，不覆盖旧版本。

安装到其他agent支持的技能目录，可指定目标技能文件夹：

```powershell
& '.\install.ps1' -Destination 'D:\AgentSkills\role-showcase-remix'
```

单独显示引导：`run.cmd start`。其他工具手工复制安装的环境，在第一次调用本技能时输出引导；不承诺平台未提供的安装后聊天自动弹出事件。
