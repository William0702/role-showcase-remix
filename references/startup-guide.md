# 混剪技能使用步骤

先确认本次为展示还是剧情；本页第3–4步的分组与自动制作仅适用展示。剧情使用 [逐步共创蓝图](story-collaboration.md)：本次需求确认→拉片理解→独立审阅与用户确认→同素材顺剪/蒙太奇双方案→选定→预演方案确认与制作→预演验收→完整方案确认与制作→全片验收。没有经过这些确认，不自动制作剧情成片。

安装时先检查本机FilmCraft，已有可用软件直接复用；没有则自动安装内置官方完整程序，完成实际导出自检后才开始制作。

1. 直接把视频发给Agent，或者提供现有母片文件夹路径。你不用先建立工程和制作目录。
2. Agent自动整理独立批次、母片和工作目录，盘点素材并告诉你保存位置。
3. Agent通过聊天补问未明确的模式、分组、条数、使用上限、输出规格和命名要求；已回答的直接沿用。
4. 回答完成后自动拉片、切分、排列，在FilmCraft创建工程、拼接原声并导出，通过核验后交付成品和工程。只有具体歧义或规则冲突才再问。

可直接发送：
“使用 $role-showcase-remix 自动混剪这些视频。先问我需要确定的要求，回答后自动完成FilmCraft拼接、导出和交付。目录及工程由你整理。”

当前已验证自动技术链：展示类、本批统一配额、保留原声。剧情使用独立流程，尚未实现同等已验证的自动FilmCraft映射。
技能安装目录：{SKILL_DIR}

成片交付后会补问音频是否保持、去BGM保留环境与人物念白，或先分析组成再决定；原声版本保留。

确认成片定稿后，Agent会询问是否制作英雄定格。选择需要，再逐步确认单帧、名字/排版、艺术字样张和全部静态图；原帧、纯绿版与透明层共用文字设计。之后可选绿幕文字出现或带角色环境微动的动画提示词，支持两种都要。每步支持局部重做或恢复旧版。图像设计依赖执行Agent实际可用的生成/编辑能力，不在离线包里预装AI模型；提示词不等于已生成视频。

通过GitHub稳定Release分享。在技能目录运行update.cmd获取最新稳定版，update.cmd -CheckOnly只检查。详见github-distribution.md；项目文件不进入技能包。
