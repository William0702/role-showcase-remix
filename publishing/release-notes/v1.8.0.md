# 混剪技能 v1.8.0 · Windows x64 完整包

## 安装与更新

只需下载 **role-showcase-remix-v1.8.0-windows-x64.zip**，解压后双击 **install.cmd**。这是包含 Python、FFmpeg、FFprobe、依赖及 FilmCraft 软件的完整技能包，无需下载源码或拼接分片。SHA256SUMS.txt 为可选校验文件。

已有安装在技能目录运行 **update.cmd**；如提示本地修改，先保留修改及备份，不强制覆盖。GitHub 自动附带的 Source code 不是完整安装包。

## 本版变化

- 剧情模式采用逐步共创：需求确认、完整拉片与剧情理解、同素材顺剪/单源蒙太奇双方案、预演及完整制作分阶段确认。
- 加入独立剪辑师子 Agent 审阅要求：依据原素材取证、保留分歧、不替代用户确认；不支持分派时说明并确认替代方式。
- 增加流程蓝图和项目记录模板，明确每次需求独立判断。
- 整理文档导航、左右问答测试演示和目录命名规范。展示类原有技术链保留。

## 测试状态

**按维护者决定先发布，剧情真实成片全流程随后在本地测试。** 已通过源码一致性、包文件哈希与运行时自检；这些不代表剧情理解、蒙太奇质量、独立审片及全片核听已通过真实案例验收。

剧情目前按决定表与项目脚本执行，不是已验证的自动 FilmCraft 剧情引擎。历史去 BGM 样段未获用户认可，不承诺自动无损分离；英雄定格和动画提示词仍需阶段确认及实际可用能力。技能包不含用户素材、成片、私人路径或历史对话。
