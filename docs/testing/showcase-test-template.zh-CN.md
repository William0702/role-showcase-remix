# 展示类混剪：可复制的人工测试模板

## 使用方法

将占位符换成自己的路径，按轮复制“用户发送”内容给 Agent。等待实际输出和核验后再发下一轮；不要一次粘贴全部步骤。三种场景可分别测试；案例中的 11 段只是演示数据，实际必须读取素材确定。参考[真实测试记录](showcase-test-report.zh-CN.md)。

这是一份人工交互与验收模板，不是自动测试脚本，也不是完成证明。付费生成、云端上传及额外服务仍需依照实际授权处理。

## 场景 A：首次制作，保留原声

### A1 启动

用户发送：

```text
使用 $role-showcase-remix 测试展示类混剪。
母片目录：[母片目录]
工作目录：[工作目录；也可由你整理后告诉我]
请先检查技能版本和所需工具，告诉我实际找到的母片数量和项目路径。
需要确定的要求分轮问我，确认后继续制作。
```

预期：检查真实文件和环境；缺工具时说明所需依赖及自检结果。工具不可用时不得假称已拉片、切分或导出。

### A2 回答制作规则

收到对应问题后，用户发送：

```text
展示类混剪，先做 10 条，每条 3 个完整角色展示片段。
不限定秒数，保留角色的完整展示、动作和变身。
采用母片画幅和帧率；如果源参数不同，先给出统一方案让我确定。
保留原声。允许跨母片混用，不设必选或排除角色。
本批每个角色片段最多使用 3 次，单条不重复同一片段。
本批角色片段集合不能重复，仅调换顺序算同一组合。
文件先用 01–10 编号。
```

预期：仅补问仍缺失或互相冲突的项目。完整拉片明确角色片段，不把同一角色的切镜、动作或变身拆成多个角色凑数。先列片段边界和组合方案，等待用户确认。

### A3 确认切分与组合

仅在自己实际查看并认可方案后发送：

```text
片段边界和组合方案已看过，可以按这版切分并制作。
请保留原始母片，输出 FilmCraft 可编辑工程、成片和实际片段使用次数表。
```

预期：依方案制作，逐条校验完整性、首尾、全部衔接、配额和组合去重；报告音频技术检查与实际核听各自的完成状态。出现纯文字无角色尾帧时，根据内容核对边界后修正，不能误删有角色的定格。

### A4 反馈或定稿

有问题时发送：

```text
第 [编号] 条在 [时间点] 有 [具体问题]，请定位对应片段并修复，复查受到影响的成片。
```

实际看过并认可后才发送：

```text
这一批混剪成片没问题，可以定稿。
```

预期：成片交付后补问音频是否处理；用户明确确认混剪定稿后，再询问是否进入英雄定格第二阶段。第二阶段的实际效果不由本模板视为已通过。

## 场景 B：更新后重做，保留已确认规则

用户发送：

```text
使用已更新的技能重新制作同一批母片，沿用之前已确认的制作规则。
本批请避开上一批全部角色片段集合，仅改变顺序不算新组合。
保留旧工程与旧成片，新批单独保存。请核对当前版本与素材是否变化。
```

预期：核对版本和源文件哈希；原完整拉片证据存在且素材未变时可复用，不能声称重新看过全部帧。素材变化或证据缺失则重新审核相关素材。配额范围沿用本批，检查历史组合交集；无可行方案时先报告冲突。

## 场景 C：清空规则重测，容量冲突与去 BGM

### C1 明确重置

用户发送：

```text
仍用上述母片，但之前确认的制作规则全部清空，重新问答。
这次做展示类，目标 15 条，每条 3 个完整角色片段，每个片段最多 3 次。
先确认是否可行，不要为了达到数量拆散同一角色展示。
```

预期：重新确认配额范围等缺失项。必要使用容量上限为 floor(完整片段数×使用上限÷每条片段数)，还要检查组合去重等额外约束；容量足够不代表全部条件一定可行。

### C2 补齐音频和范围

收到对应问题后发送：

```text
次数按本批计算。采用母片画幅和帧率。
希望去 BGM，保留角色念白/对白、环境音、动作和法术音效。
跨母片自由组合，单条不重复片段；允许复用历史组合，本批集合不重复。
请先检查音轨组成和处理工具，保留原声备份，先给短样段，核听通过再批量处理。
```

预期：区分混合音轨与可独立删除的音乐轨；没有验证过的分离工具时说明能力边界。不能以提取音轨成功代替去 BGM 成功。

### C3 容量不足时改方案

如果实际仍为 11 段，则 15 条需要 45 次，最多只有 33 次。Agent 应提供可行调整供选择。用户选择减少数量时发送：

```text
保留本批每段最多 3 次，改做 11 条，编号 01–11。
请重新列组合方案和使用次数，确认无误后再制作。
```

如果实际片段数不同，请按实际容量选择新数量，不机械采用 11 条。Agent 不得擅自增加次数或降低产量。

### C4 音频失败反馈

实际听到问题后发送：

```text
样段在 [时间区间] 仍有明显 BGM 残留，暂不通过。
请保留上一版，给出有针对性的修订样段，并说明对白和环境/动作音效是否损失；先不要批量应用。
```

仍失败时发送：

```text
仍有残留，当前方案不通过。请说明继续使用同一方法的局限，给出替代方案让我选择。
```

预期：记录拒绝，暂停批量音频替换；提供原声/处理后对应时间对比。未核听不能宣称听感通过。候选输出完成与用户验收通过分开记录。

### C5 音频通过（仅在实际认可后使用）

```text
我已核听 [样段版本]，这一版去 BGM 和保留人声、音效的效果可以。
按这一版处理本批全部 [数量] 条，保留原声备份；批量完成后检查音画同步、时长和音频完整性，再给我验收。
```

预期：只采用被认可的版本和范围；批量交付仍需用户查看确认，不能用短样段通过替代所有成片的检查。
