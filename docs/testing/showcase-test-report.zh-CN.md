# 展示类混剪：真实测试对话参考

## 阅读边界

依据一次真实测试对话整理，已匿名化和归纳，不是逐字聊天导出。以下“报告通过”均指原对话中 Agent 的报告，整理文档时未重新打开媒体核验，也未重新运行制作测试。用户明确否决的去 BGM 效果不计为通过。

案例使用三部母片，统一称 source_A、source_B、source_C；所有工作路径和文件名均以占位符表示。案例数值仅说明这次测试，不是技能默认参数。源素材、成片、音频、工程和下载模型不随文档公开。

## 1. 环境恢复

用户要求使用技能自动混剪三部母片，先询问缺失要求，再自动整理工程并制作。首次本地工具启动失败，未开始制作。用户要求先恢复工具后，Agent 报告技能、三部母片、Python、FFmpeg、FFprobe 与包校验可用。

参考行为：工具失败时如实说明停在哪一步；使用当前环境允许的执行方式恢复，实际验证成功后再继续。不要把本次主机的执行故障及恢复方式作为所有安装者必须经历的步骤。

## 2. 第一批：10 条，保留原声

确认要求：按完整角色展示重排，10 条，每条 3 个角色片段；时长由完整片段决定；采用母片画幅；原声；跨母片自由组合；本批单片段最多 3 次；自动编号 01–10。

Agent 报告完整查看 4,024 帧，识别 11 个完整角色片段，三部母片分别为 4、4、3 段。同角色的景别、动作、变身仍归在同一完整片段。去除一帧无角色的纯文字黑画面，保留有角色的定格、动作及变身内容。

交付报告：10 个 FilmCraft 可编辑工程与原生导出视频；1280×720、30fps；每条 3 个不同片段；批内角色集合不重复；时长 33.67–39.97 秒。30 次使用分布为 8 段各 3 次、3 段各 2 次；检查每条首尾和全部 20 处衔接。原声技术检查报告通过，未独立核听，不能据此宣称听感验收通过。

## 3. 第二批：更新技能，沿用要求，避开旧组合

用户要求更新技能后重新制作，没有要求清空规则。Agent 沿用已确认参数，仅补问是否避开上一批角色组合；用户选择全部新组合。

源文件哈希未变，沿用原完整拉片证据。报告新制作 10 条，与上一批角色集合重叠为 0；本批每段使用 1–3 次；时长 35.03–39.80 秒；检查首尾和 20 处衔接。旧批工程与成片保留。未独立核听。

“新组合”按角色片段集合判断：同样三个片段只交换顺序，仍算同一个组合。配额按已经确认的“本批”计算，不擅自扩展为历史累计。

## 4. 第三批：明确重置，发现容量冲突

用户明确要求此前所有确定内容不再采用，重新走流程。重新确认得到：展示类、15 条、每条 3 段、本批每段最多 3 次、源画幅帧率、去 BGM，并保留角色念白/对白、环境音、动作及法术音效。

重新检查仍有 11 个完整角色片段。15×3 需要 45 次使用，11×3 只有 33 次容量。Agent 提出调高上限、减少数量或增加至少 4 段完整素材；用户选择保留最多 3 次，改为 11 条，编号随之改为 01–11。

进一步确认：跨母片自由混用；单条不重复同一片段；允许与历史批次组合相同，但本批角色集合不重复。本批 11×3=33 次，因而这一次恰好每个片段各用 3 次；“最多 3 次”本身不要求一般任务都必须用满。

## 5. 原声备份交付与音频试样

Agent 报告完成 11 个 FilmCraft 工程和原声备份视频：每条 3 段、33.67–38.43 秒；每段恰好使用 3 次；批内集合不重复；已检查首尾和全部 22 处衔接。

母片只有混合立体声音轨，不能当作独立 BGM 轨直接删除。另行尝试了外部 BandIt v2 系列模型的分离实验；本记录不能证明该模型已成为技能内置依赖，具体成功加载的变体不从简略对话推定。模型下载、校验或加载成功不等于去 BGM 效果通过。

先对三部母片各制作约 12 秒对比样段，并提供原声、处理后及分离音轨供核听。未独立核听，未批量替换 11 条成片音频。
